# W1 — esqueleto web

**Objetivo:** una aplicación Angular + Ionic en `web/` que carga los artefactos de fixture y muestra matemática compuesta. Sobre ella se construyen W2 (cara estudiante) y W3 (cara profesor).

**Especificación:** `docs/diseno.md`, secciones 5.1, 5.3, 5.5 y 5.7. **Contratos:** `contracts/`.

**Carpetas que tocas:** `web/` y `.github/workflows/web.yml`. Nada más.

## Restricciones

- Última versión estable de Angular y de `@ionic/angular`, componentes *standalone*, TypeScript estricto. Confirma en la documentación actual cómo se crea el proyecto y qué ejecutor de pruebas trae por defecto; usa ese.
- Interfaz en español; código, comentarios y commits en inglés (Conventional Commits).
- La aplicación debe funcionar alojada en una subcarpeta: sin rutas absolutas a recursos; `base href` configurable al compilar.
- Sin analítica, sin fuentes ni scripts de CDN. KaTeX y sus fuentes van empaquetados desde npm.
- Nunca insertes HTML sin escapar que venga de los artefactos o del usuario.
- No implementes todavía el cuestionario, el mapa de errores, el modelo en el navegador ni el servicio de LLM: son W2, W3 y S1.

## Entregables

1. **Proyecto** en `web/` con scripts `npm start`, `npm test` (una pasada, sin navegador visible), `npm run build`, `npm run lint`.
2. **Tipos** en `web/src/app/core/contracts.ts`, espejo exacto de los esquemas: `Catalog`, `CatalogItem`, `Bank`, `Question`, `OptionLetter` (`'A' | 'B' | 'C' | 'D'`), `Tag` (`{ error: string; score: number; source: 'gold' | 'model' }`), `Manifest`.
3. **`ArtifactsService`** en `web/src/app/core/artifacts.service.ts`:
   - `loadCatalog(): Promise<Catalog>`, `loadBank(): Promise<Bank>`, `loadManifest(): Promise<Manifest>`, `loadEmbeddings(): Promise<Float32Array>`.
   - Lee de una URL base inyectable (`ARTIFACTS_BASE_URL`, por defecto `assets/artifacts/`), guarda cada resultado en memoria tras la primera carga.
   - Rechaza con `ArtifactError` si `version !== 1` o si `catalog.f32` no mide `n_catalog * dim * 4` bytes.
4. **Fixtures como artefactos:** `angular.json` copia `../contracts/fixtures/**` a `assets/artifacts/`. No dupliques los archivos dentro de `web/`.
5. **`MathTextComponent`** (`app-math-text`, entrada `text: string`): muestra texto con `$...$` (en línea) y `$$...$$` (bloque) compuesto con KaTeX; el resto como texto plano, respetando saltos de línea. LaTeX inválido se muestra como su fuente, marcado como error, sin lanzar excepción.
6. **Rutas y páginas:** `/` (inicio, con dos tarjetas: "Practicar" y "Diagnosticar una pregunta"), `/practicar` y `/diagnosticar` (páginas vacías con título, para W2 y W3), `/acerca` (qué es, que el diagnóstico es una hipótesis, que nada sale del dispositivo). El inicio muestra además el enunciado y las alternativas de la pregunta `F-01` del banco de fixture, compuestos.
7. **CI** en `.github/workflows/web.yml`: en cambios bajo `web/` o `contracts/`, ejecutar `npm ci`, `npm run lint`, `npm test`, `npm run build` dentro de `web/`.

## Pruebas obligatorias

- `MathTextComponent` con `¿Cuánto es $\frac{1}{2}$?` produce un elemento con clase `katex` que contiene un `.mfrac`, y conserva el texto `¿Cuánto es`.
- `MathTextComponent` con `$\frac{1}{$` no lanza y muestra la fuente.
- `MathTextComponent` con `<img src=x onerror=alert(1)>` no crea ningún elemento `img`.
- `ArtifactsService.loadBank()` devuelve 5 preguntas con el fixture y hace una sola petición aunque se llame dos veces.
- `ArtifactsService.loadCatalog()` rechaza con `ArtifactError` ante `{"version": 2, ...}`.
- `ArtifactsService.loadEmbeddings()` devuelve un `Float32Array` de longitud `6 * 384` con el fixture y rechaza si el tamaño no calza.

## Criterio de aceptación

`npm run lint`, `npm test` y `npm run build` pasan dentro de `web/`. Con `npm start`, la página de inicio muestra la fracción de `F-01` compuesta.
