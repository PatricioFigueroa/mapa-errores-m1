# W3 report: teacher face

Date: 2026-11-10. Branch: `pkg/w3-profesor`. Model: GPT-6 Codex. Work left uncommitted.

## Implemented

- Added exact E5 query/passage formatting, cosine ranking over normalized vectors, top-three diagnosis and threshold abstention.
- Added an on-demand Web Worker for quantized Transformers.js feature extraction with mean pooling and normalized vectors. The teacher explicitly starts the model load; status and download progress are shown. The default source is `Xenova/multilingual-e5-small`; `MODEL_SOURCE` supports a local directory.
- Added the optional API adapter for structuring and reinforcement. HTTP and network failures become `ApiUnavailableError`; the page retains the manual form and catalog activity.
- Added the teacher form with live KaTeX previews, validation, optional distractor counts, ranked results, hypothesis notice, and a `bank.json`-shaped download. Reused `ArtifactsService`, `MathTextComponent`, and the shared contracts. Changed only the `diagnosticar` route in `app.routes.ts`.
- Added every test listed under **Pruebas obligatorias**. The export test checks the bank/question keys, required field types, distractor-only tags, tag shape, score bounds and `model` source.

## Decisions and limits

- The fixture manifest has `model_id: fixture-random-vectors`, so its `catalog.f32` is skipped and catalog passages are embedded in browser memory. Other manifests use `ArtifactsService.loadEmbeddings()`.
- A local `MODEL_SOURCE.path` is treated as the URL of the model directory; the worker derives its parent path and directory name for Transformers.js. The default Hub source is used until real artifacts exist.
- The generated download wraps one question in `{version: 1, questions: [...]}`. A blank topic exports as `sin-tema` so the bank schema still accepts it.
- Only the W3 files and the dependency/ignore files required by the user were changed. The master-plan status and log were not edited because the W3 brief's explicit file scope excludes them.
- No browser was available. I did **not** run `npm start` in a browser, download the real 118 MB model, measure load or diagnosis time, or record F-01 ranked errors. The real-worker acceptance behavior, including local-model loading, remains unverified. No measurements or model results are invented here.
