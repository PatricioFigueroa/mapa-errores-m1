## Choices

- **Fixtures as assets.** Angular refuses asset paths outside the workspace ("must be within the workspace root"), so
  `angular.json` cannot copy `../contracts/fixtures` directly. `scripts/copy-fixtures.mjs` copies them to
  `web/public/assets/artifacts` in `prestart` and `prebuild`; that folder is git-ignored, so nothing is duplicated in git.
  `npm test` does not need them: the service tests stub `fetch` and read the fixtures from `../contracts/fixtures`.
- **Fetch, not HttpClient.** `ArtifactsService` uses `fetch` and caches promises (concurrent calls share one request;
  failed loads are evicted so they can be retried). `loadEmbeddings` reads the manifest to get `n_catalog * dim * 4`.
- **MathTextComponent builds DOM nodes** (text nodes plus `katex.render`) instead of `innerHTML`, so Angular's sanitizer
  does not strip KaTeX styles and no input is parsed as HTML. Inline `$...$` is single-line; `$$...$$` may span lines.
  Invalid LaTeX is shown as source in a `.math-error` span.
- **Base href.** `index.html` has `<base href="/">`; set it at build time with `ng build --base-href /sub/`. Artifacts are
  fetched with a relative URL, so they follow the base href.
- Initial-bundle warning budget raised from 500 kB to 700 kB (Ionic core). Default `ng new` boilerplate (`app.html`,
  `app.scss`, `app.spec.ts`) removed; the root component has an inline template.
- Stylesheet: Ionic core/normalize/structure/typography CSS and `katex.min.css` (fonts bundled from npm), no CDN.
- One large feature commit instead of several small ones after the scaffold and dependency commits.
- No PWA service worker or manifest yet (not in the brief's deliverables). `zone.js` is not installed (zoneless app);
  Ionic 9 lists it as a peer dependency but npm did not complain.
