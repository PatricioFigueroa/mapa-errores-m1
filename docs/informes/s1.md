## Decisions

- Used a one-minute rolling window per IP for `PER_MINUTE`; timestamps and daily counts stay in process memory.
- Reset the daily counter when the UTC date changes, using injected `now` for deterministic tests.
- For structure responses, parse the first complete JSON object from the LLM text and retry once only when extraction or schema validation fails.
- Treated LLM transport failures and non-429 HTTP errors as unavailable; quota and unavailable errors both activate the optional fallback.
- Kept `.npm-cache`, `node_modules`, and build output ignored under `server/` so generated dependencies and artifacts are not committed.
